# Budget Tracker Instructions

Read `docs/MASTER_SPEC.md` before performing project work.

## Project stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- TanStack React Query
- React Router
- Recharts

## Required rules

- Preserve the existing project and Supabase architecture.
- Do not rebuild the application from scratch.
- Do not expose secrets or service-role keys.
- Create migrations for database changes.
- Keep the first AI assistant read-only.
- Work on one implementation phase at a time.
- Do not make unrelated changes.
- Run build, lint, and relevant tests after each task.
- Report changed files, migrations, tests, and remaining limitations.
